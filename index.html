📘 仙考不过线 | 修仙策略消除 微信灰度中抖音筹备

Roguelike × 策略消除的轻量修仙小游戏，挑战“考试式关卡”，通过组合与叠BUFF完成飞升。

🎮 项目简介

面向微信/抖音平台的“修仙题材 消除 × Roguelike”。围绕四档难度（Simple/Normal/Hell/Nightmare）与 多条成长线（角色等级、灵宠被动、灵器一次性&成长、秘籍加成、修炼组合、材料合成），塑造 8–12 分钟短局的高复玩循环； 关底配置差异化 BOSS 卡点 与 商店权重/低保底/同类加成，引导关键决策与变现。

微信：流量主（激励/插屏/格子/横幅） 抖音：激励视频 API

🧩 核心机制

  • 🔶 消除即得分：颜色分/形状分×连击×组合倍率×Buff
  • 💥 局内成长：短期/长期 Buff、金币购买、随机事件、BOSS 卡点
  • 🛒 商店策略：权重/暗保底/同类加成可配置化

🛠 当前进度

  • ✅ 已在微信小程序灰度测试；四难度可测
  • 🎯 正在集中调整 UI 表现 与 成就系统，优化新手引导与动效

💡 技术栈

Cocos Creator 3.8.x · TypeScript/JavaScript · JSON 数据配置 · 关卡/状态管理 · 动效与资源分包

🪨 符石裂界 | 回合制卡牌 × Roguelike 原型完成多职业

源于“元素魔法”世界观的回合制卡牌项目；多职业×多成长线，弱点破坏与前后排站位驱动策略。

🎮 项目简介

面向微信/抖音平台的回合制卡牌：围绕多职业（法师/圣骑士/射手/刺客/牧师/术士等）与 多成长线（职业等级、技能树/专精、天赋符印、符器/装备、材料/成就）展开。 战术轴为弱点破坏（Break）+ 前后排站位：命中要害进入易伤窗口，配合穿透/嘲讽/越位技能形成爆发回合。

🧩 核心机制

  • 🃏 回合制出牌：抽换弃循环、能量与疲劳管理、连锁与计时
  • 🎯 弱点系统：部位弱点/护盾/免疫/沉默等词缀可配置，Break 进入易伤
  • 🧱 站位博弈：前后排、穿透/嘲讽/越位、区域技能与目标优先级

🛠 当前进度

  • ✅ 核心玩法框架完成：回合流程、弱点破坏、站位规则与基础 AI
  • 🧪 职业雏形与卡池原型已就绪，教学/UI/动效打磨中

💡 技术栈

🧪 AI 游戏实验（非商业化）

🐾 灵伴奇缘 | AI宠物陪伴游戏

“陪伴+冒险”双机制；行为受体力/生命/羁绊/金币等数值驱动，形象与情绪由 AI 动态生成。

🎮 项目简介

玩家领养专属虚拟宠物，通过喂养、交流、冒险等培养互动。冒险融合回合制事件、多轮对话、任务分支， 行动与反馈绑定数值循环；集成 Stable Diffusion 与 SadTalker，根据状态生成外观/表情/语音。 🌐 点击试玩：《灵伴奇缘》网页版

💡 技术栈

Coze（多轮智能体/知识库/API） · Stable Diffusion · SadTalker · JS/HTML5 · 状态驱动行为/事件模块

🧠 AI合成游戏 | AI Synthesis Game

类《Infinite Craft》合成探索：本地 LLM + 图像生成驱动的创意玩法。

🎮 项目简介

通过拖动并合成基础元素（金木水火土）不断解锁新元素；结合本地 Ollama 与 Stable Diffusion， 自动生成神兽图像与背景，支持合成历史复用与策略探索。

🔧 我负责的内容

  • 玩法系统设计：元素合成规则、神兽设定、探索流程
  • Unity 开发：拖拽/碰撞、元素生成、合成历史
  • AI 集成：Ollama（Llama3）合成逻辑、SD 生成神兽图像
  • UI 与成就：解锁弹窗、进度记录、背景切换

祖龙娱乐 -《龙族：卡塞尔之门》

为 二次元类型的《龙族：卡塞尔之门》游戏中《诺玛》角色打造的 AI 对话助手，伪装为 NPC 与玩家互动，显著提升游戏的社交氛围与热度。

🧠 项目定位

“诺玛” 是游戏世界中的拟人化 AI 角色，具备故事背景与个性设定，能够主动与玩家对话，回答任务相关问题，引导剧情进展，并进行自然闲聊，成为玩家热议焦点。

🔧 我的职责

  • 人设与交互设计：构建角色人格与行为逻辑，设定多轮对话路径与语气风格
  • Prompt 工程搭建：设计剧情触发语、任务问询回应、趣味对话等多个交互意图
  • 模型集成落地：协同开发接入大模型与游戏引擎系统，优化上下文理解与性能表现
  • 玩法反馈分析：收集玩家行为数据与对话记录，推动多轮版本迭代与交互优化

✨ 技术亮点

  • 🎭 游戏内 AI NPC 拟人化呈现，支持自由问答与情感表达
  • 🛠️ 多轮对话机制，结合剧情节奏与任务节点动态应答
  • 🎮 UE4 场景触发器联动，自然嵌入游戏流程
  • 🔄 提升玩家平均停留时长与社交传播热度
