海底刺鱼｜场景、新手与玩家心流设计

独立负责新手流程与场景方向，从大量游戏 / 影视参考中提炼海底探索、鱼群运动、 场景引导和阶段演绎方式，并落到流程、事件、配置和实机体验。

新手流程场景设计事件演绎 鱼群配置心流AI概念图

设计方法

  • 体验路径：围绕“探索 → 发现 → 行动 → 阶段惊喜”设计新手节奏。
  • 场景与引导：通过地标、地形、鱼群运动、事件触发和镜头表现引导玩家。
  • 配置落地：明确鱼种、数量、大小、颜色、游动方向和速度，并参与场景搭建。
  • AI辅助：快速制作场景概念图、地图点位和玩法 / UI 效果图，在正式制作前对齐方向。

公开展示原则

🔒 商业项目受保密协议限制：仅展示可公开的方法、流程和部分推广素材， 不展示内部配置、未公开版本和敏感数据。
